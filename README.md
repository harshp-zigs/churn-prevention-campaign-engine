## Quick checklist

- [ ] Tag every ad link with campaign parameters
- [ ] Add hidden source fields to each form
- [ ] Define deduplication and scoring rules
- [ ] Set routing and alert rules
- [ ] Send outcomes back to ad platforms

## Terms

- **Funnel sync:** automatic movement of lead data between ads, forms, CRM and marketing tools.
- **Qualified lead:** a lead that matches fit criteria and shows real interest.
- **Click ID:** the identifier an ad platform attaches to a click.
- **Deduplication:** merging records that belong to the same person.
- **Offline conversion:** a sales result sent back to an ad platform after the fact.
